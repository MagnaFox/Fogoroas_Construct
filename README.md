# 🏗️ Fogoroas Construct (Construye Firme)

Landing page profesional y moderna para una empresa / cuadrilla de construcción residencial enfocada en obras de pequeña y mediana escala (habitaciones, bodegas, ampliaciones y terminaciones de hasta 2 pisos).

---

## 🌟 Características

- **Diseño visual moderno y responsivo:** Paleta de colores balanceada, tipografía cuidada (Inter & Outfit), animaciones suaves al hacer scroll y diseño adaptable a móviles.
- **Hero con carrusel interactivo:** Transición automática y manual con navegación por flechas y puntos indicadores.
- **Sección de Servicios:** Habitaciones independientes, bodegas/almacenes, extensiones/segundos pisos, remodelaciones de baños/cocinas, muros y cercos perimetrales, y acabados finos.
- **Portafolio de Proyectos con Filtros:** Galería interactiva filtrable por categoría.
- **Sección de Contacto Dual:**
  - Formulario para **Clientes** (solicitud de cotización).
  - Formulario para **Trabajadores / Jornaleros** (postulación por días de obra).
- **Acceso rápido y WhatsApp Flotante:** Botón directo a WhatsApp para atención inmediata.
- **Componentes adicionales:** Estadísticas dinámicas, testimonios, proceso de trabajo paso a paso y presentación del equipo.

## 🚀 Cómo ejecutar localmente

Puedes servir la página con cualquier servidor estático local:

```bash
# Con Node.js / npx serve
npx serve . -p 3000

# Con Python
python -m http.server 3000
```

Luego abre tu navegador en `http://localhost:3000` o desde tu red local con `http://<TU_IP_LOCAL>:3000`.
